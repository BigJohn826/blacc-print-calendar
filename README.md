# Blacc Print Calendar Portal

A lightweight, mobile-first schedule portal for Blacc Print Experience.

## Purpose
One link, one schedule, one source of truth for upcoming BPE gigs.

## Current features
- Next gig
- This week
- Upcoming gigs grouped by month
- Search
- Confirmed / Needs Details status
- Expandable gig details
- One-tap map links

The schedule is maintained from BPE gig information and can be updated as new details arrive.
